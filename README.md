> [!WARNING]
>
> ### АНТИВИРУСНОЕ ПО
>
> Для работы zapret требуется WinDivert — средство перехвата и фильтрации сетевого трафика. Антивирус может отреагировать на него, хотя сам WinDivert вирусом не является: такой инструмент способны использовать как безопасные, так и вредоносные программы.
>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) проекта [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle):**
>
> Некоторые антивирусы считают файлы WinDivert потенциально опасными или относят их к хакерским инструментам. В результате файл удаляется и отправляется в карантин. В названии обнаружения обычно присутствует `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Добавьте каталог с zapret в исключения антивируса либо отключите обнаружение PUA (потенциально нежелательных приложений). Например, в Kaspersky есть настройка "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы уверенно понимаете настройки исключений, предпочтительно добавить исключение; при сомнениях рекомендуется отключить детектирование PUA.

## ⚙️ Использование

1. Настройте Безопасный DNS (Secure DNS).
   * В Chrome включите "Использовать безопасный DNS" и выберите поставщика, отличного от "Поставщика по умолчанию".
   * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`. Это может быть полезно, если Cloudflare заблокирован.
   * Windows 11 позволяет включить Secure DNS непосредственно в настройках системы — [инструкция](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот вариант рекомендуется.
   * На роутерах Keenetic включите параметр "Транзит запросов". При отключенной настройке Secure DNS на компьютере может работать некорректно.

2. Скачайте zip- или rar-архив с [последнего релиза](https://github.com/Meshshugranary/zapret-discord-youtube/releases/latest).

3. Откройте свойства архива и установите флажок "Разблокировать". При использовании 7-Zip или PeaZip этот шаг можно пропустить.

4. Распакуйте архив в путь без кириллицы и специальных символов.

5. Запустите подходящий файл:
   * Для поиска рабочей стратегии откройте **`service.bat`** и выберите `Run Tests` -> `Standard tests` -> `All configs`.
   * Для автоматического запуска откройте **`service.bat`**, выберите `Install Service`, затем укажите подходящую стратегию.

## ℹ️ Назначение файлов

- [**`general.bat ...`**](./general.bat) запускает стратегию вручную.

  Такой запуск удобен для проверки стратегий. Результат зависит от множества условий, поэтому попробуйте несколько вариантов — **ALT, FAKE и другие**, пока не найдёте подходящий.

- [**`service.bat`**](./service.bat) содержит установку автозапуска и дополнительные операции:
  - <ins>**`Install Service`** — добавить выбранную стратегию в автозапуск через services.msc.</ins>
  - **`Remove Services`** — удалить стратегию и WinDivert из служб.
  - **`Check Status`** — проверить состояние обхода и служб, включая автозапущенную стратегию и WinDivert.
  - **`Game Filter`** — изменить режим обхода для игр и других сервисов, использующих UDP и TCP на портах выше 1023.  
  После смены режима стратегию нужно перезапустить. В скобках отображается текущий статус: включено или выключено.
  - **`IPSet Filter`** — изменить режим обработки сервисов из `ipset-all.txt`. Это полезно при проверке ресурса, который без zapret работает, а с ним — нет.  
  В скобках показывается состояние:
    - `none` — ни один IP не проходит проверку;
    - `loaded` — IP проверяется на наличие в списке;
    - `any` — под фильтр попадает любой IP.
  - **`Auto-Update Check`** — включить или выключить автоматическую проверку обновлений.
  - **`Replace active fakes`** — заменить используемый фейк другим файлом из `bin`.
  - **`Update IPSet List`** — загрузить актуальный `ipset-all.txt` из репозитория.
  - **`Update Hosts File`** — обновить hosts <ins>для восстановления веб-версии Telegram и подключения к голосовому чату Discord.</ins>
  - **`Check for Updates`** — вручную проверить наличие обновлений.
  - **`Run Diagnostics`** — проверить распространённые причины неисправности zapret. В конце можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает при внезапном прекращении работы.
  - **`Run Tests`** — проверить стратегии:
    - `Standard tests` — тестирует сайты из `utils/targets.txt`;
    - `DPI checkers` — проверяет DPI у разных провайдеров, включая Cloudflare и Amazon.

## ☑️ Частые вопросы и неполадки

### После запуска `general*` ничего не видно

При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe, который можно увидеть на панели задач.  
Если процесс не запустился, обратитесь к [#522](https://github.com/Meshshugranary/zapret-discord-youtube/issues/522).

### Не подходит ни одна стратегия

1. Откройте командную строку от имени администратора.
2. Выполните команды по очереди:

   `netsh winsock reset`

   `netsh int ip reset all`

   `netsh winhttp reset proxy`

   `ipconfig /flushdns`

3. Перезагрузите компьютер.

### Не открывается Telegram в браузере

В **`service.bat`** выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:

- скопируйте весь текст из открывшегося блокнота;
- откройте файл `hosts` в созданном каталоге через текстовый редактор, запущенный от имени администратора;
- добавьте скопированный текст в конец `hosts` или замените ранее добавленные аналогичные строки;
- сохраните файл и проверьте подключение. Если результата нет, убедитесь, что изменения действительно сохранились.

#### Результат не гарантируется. Если веб-версия по-прежнему не работает, используйте [Telegram Desktop](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/Meshshugranary/tg-ws-proxy) или публичным прокси.

### Обход не работает или перестал работать

> [!IMPORTANT]
> **Стратегии могут терять работоспособность со временем.**
> Стратегия иногда работает некоторое время, а затем перестаёт из-за обнаружения метода обхода.
> В проекте есть много стратегий. Если готовые варианты не помогают, создайте новую на основе одной из них и измените её параметры.
> Описание параметров находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- В `service.bat` -> `Run Diagnostics` проверьте наличие ошибок.
- Убедитесь, что адрес нужного ресурса внесён в списки доменов или IP.
- Проверьте другие стратегии, в том числе **`ALT`** и **`FAKE`**.
- Выполните полную переустановку по инструкции ниже.
- Дополнительная информация есть в [#765](https://github.com/Meshshugranary/zapret-discord-youtube/issues/765).

### Как полностью переустановить или обновить проект?

- Сохраните добавленные вами ресурсы и другие данные.
- Перезапустите компьютер.
- Выполните `service.bat` -> `Remove Services`.
- Запустите `service.bat` -> `Run Diagnostics`; исправьте ошибки и в конце подтвердите действие клавишей Y.
- Удалите каталог zapret.
- Скачайте новую версию со [страницы релизов](https://github.com/Meshshugranary/zapret-discord-youtube/releases), архив `zapret-discord-youtube-...`.
- Откройте свойства архива правой кнопкой мыши. Если внизу окна есть пункт разблокировки, отметьте его, нажмите "Применить", затем "ОК".
- Распакуйте архив в новую папку в корне диска, исключив пробелы, специальные символы и кириллицу.
- Запускайте разные `general`-скрипты и проверяйте доступность ресурсов. Если соединение не работает, закройте программу через значок замка на панели задач и попробуйте другую стратегию.
- После выбора рабочей стратегии добавьте её в автозапуск через `service.bat` -> `Install Service`.

### Игра или приложение не работает при включённом zapret

В `service.bat` проверьте, что `Game Filter` имеет статус **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит обнаруживает WinDivert

Инструкция доступна [здесь](https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide).

### Windows 7 требует цифровую подпись драйвера WinDivert

Замените `WinDivert.dll` и `WinDivert64.sys` в [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert остаётся среди служб

1. В командной строке Windows, открытой через Win+R и `cmd`, найдите имя службы:

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8F-использование).
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Если рабочая стратегия раньше перестала помогать, проверьте остальные варианты.
- Дополнительные сведения: [#251](https://github.com/Meshshugranary/zapret-discord-youtube/discussions/251).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что включён [Secure DNS](#%EF%B8%8F-использование).
- Сначала определите стратегию, на которой открывается YouTube, и запустите её.
- В `service.bat` откройте `Run Diagnostics` и очистите кэш Discord.
- Проверьте, помогла ли очистка кэша в приложении Discord.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, временно используйте её.
- Если Discord не открывается и в браузере, попробуйте все стратегии ещё раз: YouTube и Discord могут работать на разных вариантах.
- См. также [#252](https://github.com/Meshshugranary/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Используйте [tg-ws-proxy](https://github.com/Meshshugranary/tg-ws-proxy).
- Либо подключите бесплатный MTProto-прокси из интернета.

### Не запускаются игры или нет соединения

Игр много, поэтому проверить и исправить каждую отдельно невозможно.

Попробуйте следующий общий порядок действий:

- обновите ipset через `service.bat` и включите `Game Filter`;
- если это не помогло, дополнительно включите режим `ipset any`.

Учитывайте, что `ipset any` может нарушить открытие многих сайтов. Не оставляйте этот режим включённым постоянно: определите все IP-адреса игры и добавьте их в `ipset-all.txt`.

Если проблема сохраняется, создайте обсуждение в разделе [Discussions](https://github.com/Meshshugranary/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### В списке нет моей проблемы

Создайте обращение [здесь](https://github.com/Meshshugranary/zapret-discord-youtube/issues).

## 🗒️ Добавление адресов других ресурсов

Дополнительные адреса для обхода указываются в следующих файлах:

- **`list-general-user.txt`** — домены; поддомены учитываются автоматически;
- **`list-exclude-user.txt`** — домены, которые нужно исключить, например когда IP-сеть есть в `ipset-all.txt`, но конкретный домен фильтровать не следует;
- **`ipset-all.txt`** — IP-адреса и подсети;
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, которые требуется исключить.

Файлы **`*-user.txt`** автоматически создаются при первом запуске `zapret` или `service.bat`.
