> Это средство перехвата и фильтрации сетевого трафика, необходимое для работы zapret.
> WinDivert может применяться как безопасными, так и вредоносными программами, однако сам вирусом не является.
>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) из репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)**
>
> Некоторые антивирусы классифицируют компоненты WinDivert как инструменты повышенного риска или хакерские средства. В результате файл удаляется и отправляется в карантин. В названии обнаружения обычно присутствует `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Добавьте каталог zapret в исключения антивируса либо отключите обнаружение PUA — потенциально нежелательных приложений. Например, в Kaspersky есть параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы уверенно умеете настраивать исключения, предпочтительнее добавить исключение. При сомнениях рекомендуется отключить обнаружение PUA.

## ⚙️ Использование

1. Сначала включите безопасный DNS (Secure DNS).
    * В Chrome активируйте "Использовать безопасный DNS" и выберите поставщика, отличного от "Поставщик по умолчанию".
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован.
    * Windows 11 позволяет включить Secure DNS непосредственно в настройках системы — [инструкция](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот способ рекомендуется.
    * Владельцам роутеров Keenetic нужно активировать параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать некорректно.

2. Загрузите zip- или rar-архив со [страницы последнего релиза](https://github.com/Meshshugranary/zapret-discord-youtube/releases/latest).

3. Откройте свойства архива и отметьте "Разблокировать". Для архивов, распаковываемых через 7-Zip или PeaZip, этот пункт можно не выполнять.

4. Распакуйте архив в путь без кириллицы и специальных символов.

5. Запустите нужный файл:
    * Для поиска подходящей стратегии откройте **`service.bat`** → `Run Tests` → `Standard tests` → `All configs`.
    * Чтобы включить запуск вместе с системой, выберите **`service.bat`** → `Install Service` → подходящую стратегию.

## ℹ️ Назначение файлов

- [**`general.bat ...`**](./general.bat) запускает стратегию вручную.

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества условий, поэтому **перебирайте стратегии ALT, FAKE и другие, пока не найдёте работающий именно у вас вариант**.

- [**`service.bat`**](./service.bat) содержит установку автозапуска и дополнительные инструменты:
  - <ins>**`Install Service`** — добавить выбранную стратегию в автозапуск через services.msc.</ins>
  - **`Remove Services`** — удалить стратегию и WinDivert из списка служб.
  - **`Check Status`** — посмотреть состояние обхода и служб, включая стратегию автозапуска и WinDivert.
  - **`Game Filter`** — изменить режим обхода для игр и прочих сервисов, работающих с UDP и TCP-портами выше 1023.  
  **После изменения параметра стратегию необходимо перезапустить.**  
  Значение в скобках показывает текущий статус: включено или выключено.
  - **`IPSet Filter`** — включить или отключить обработку сервисов из `ipset-all.txt`.  
  Этот пункт полезен во время диагностики ресурса, который без zapret не открывается.  
  В скобках отображается выбранный режим:
    - `none` — IP-адреса не проходят проверку;
    - `loaded` — проверяется наличие IP в списке;
    - `any` — под фильтр попадает любой IP.  
  - **`Auto-Update Check`** — управлять автоматической проверкой обновлений.
  - **`Replace active fakes`** — заменить используемый fake на другой файл из каталога `bin`.
  - **`Update IPSet List`** — загрузить актуальный `ipset-all.txt` из репозитория.
  - **`Update Hosts File`** — обновить hosts <ins>для восстановления веб-версии Telegram и соединения с голосовым чатом Discord.</ins>
  - **`Check for Updates`** — вручную проверить наличие обновлений.
  - **`Run Diagnostics`** — найти распространённые причины, из-за которых zapret не запускается или не работает.  
  В конце диагностики можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает после внезапного прекращения работы.
  - **`Run Tests`** — открыть инструмент проверки стратегий:
    - `Standard tests` — тестировать сайты из `utils/targets.txt`;
    - `DPI checkers` — проверять DPI у разных провайдеров, включая Cloudflare и Amazon.

## ☑️ Частые вопросы и неисправности

### После запуска `general*` ничего не видно

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe. Его можно увидеть на панели задач.  
Если процесс не запустился, обратитесь к [#522](https://github.com/Meshshugranary/zapret-discord-youtube/issues/522).

### Не подходит ни одна стратегия

- Откройте командную строку с правами администратора.
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`
  
- Перезагрузите компьютер.

### Не открывается Telegram в браузере

Запустите **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открытого блокнота.
  - Откройте файл `hosts` в созданной папке текстовым редактором, запущенным от имени администратора.
  - Вставьте скопированное содержимое в конец `hosts` или замените ранее добавленные аналогичные строки.
  - Сохраните файл и проверьте подключение. Если результата нет, убедитесь, что изменения действительно записались.

#### Результат не гарантируется. Если способ не помог, используйте [Telegram Desktop](https://github.com/telegramdesktop/tdesktop/releases) вместе с [локальным прокси](https://github.com/Meshshugranary/tg-ws-proxy) или любым публичным прокси.

### Обход не запускается или прекратил работать

> [!IMPORTANT]
> **Со временем отдельные стратегии могут перестать работать.**
> Вариант, который некоторое время обходил блокировку, может перестать помогать после его обнаружения.
> В репозитории собрано много стратегий. Если готовые варианты не подходят, создайте собственную на основе одной из них, изменив параметры.
> Описание параметров находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Убедитесь, что `service.bat` → `Run Diagnostics` не показывает ошибок.

- Проверьте, что нужный адрес присутствует в доменных или IP-списках.

- Переберите другие варианты, включая **`ALT`**, **`FAKE`** и остальные стратегии.

- Выполните полную переустановку по инструкции ниже.

- Дополнительная информация: [#765](https://github.com/Meshshugranary/zapret-discord-youtube/issues/765).

### Как полностью обновить или переустановить проект?

- Сохраните ресурсы и данные, которые добавляли самостоятельно.
- Перезагрузите устройство.
- Откройте `service.bat` → `Remove Services`.
- Запустите `service.bat` → `Run Diagnostics`; исправьте найденные ошибки и в конце ответьте Y.
- Удалите старый каталог zapret.
- Скачайте свежую версию [со страницы релизов](https://github.com/Meshshugranary/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`).
- Нажмите ПКМ по архиву и откройте свойства. Если внизу справа есть пункт разблокировки, отметьте его, нажмите применить и затем ОК.
- Распакуйте архив в новый каталог в корне диска, исключив пробелы, специальные символы и кириллицу.
- По очереди попробуйте разные скрипты `general`. Проверяйте нужные интернет-ресурсы; при неработающем варианте закройте программу через значок замка на панели задач и запустите другую стратегию.
- После выбора рабочего варианта добавьте его в автозапуск через `service.bat` → `Install Service` → нужная стратегия.

### Игра или приложение не работает при включённом обходе

- В `service.bat` проверьте, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит обнаруживает WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert остаётся среди служб

1. Получите имя службы командой в Windows CMD, открытой через Win+R → `cmd`:

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, что [Secure DNS](#%EF%B8%8Fиспользование) настроен.
- Отключите блокировщик рекламы: известно, что YouTube начал активно бороться с такими расширениями.
- Перезапустите проверку со всеми остальными стратегиями, особенно если раньше всё работало.
- См. также [#251](https://github.com/Meshshugranary/zapret-discord-youtube/discussions/251).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS](#%EF%B8%8Fиспользование) включён.
- Сначала определите стратегию, на которой открывается YouTube, и запустите именно её.
- В `service.bat` выберите `Run Diagnostics` и выполните очистку кэша Discord.
- Проверьте, заработало ли приложение после очистки.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно временно пользоваться ей.
- Если Discord не открывается и в браузере, повторите проверку всех стратегий: YouTube и Discord могут работать на разных вариантах.
- См. также [#252](https://github.com/Meshshugranary/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/Meshshugranary/tg-ws-proxy).
- Также можно использовать бесплатные MTProto-прокси, доступные в интернете.

### Не запускаются игры

Игр много, поэтому проверить и исправить каждую отдельно невозможно.

Начните с универсальной последовательности:
- через `service.bat` обновите ipset и активируйте `Game Filter`;
- если этого недостаточно, дополнительно включите `ipset any`.

Учтите, что режим `ipset any` способен нарушить открытие множества сайтов. Не оставляйте его включённым постоянно. Лучше выяснить IP-адреса, используемые игрой, и добавить их в `ipset-all.txt`.

Если и это не решило проблему, создайте обсуждение в разделе [Discussions](https://github.com/Meshshugranary/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Проблемы нет в списке

- Сообщите о ней [здесь](https://github.com/Meshshugranary/zapret-discord-youtube/issues).

## 🗒️ Добавление адресов других ресурсов

Расширить перечень адресов для обхода можно через следующие файлы:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически;
- **`list-exclude-user.txt`** — домены, которые нужно исключить, например когда IP-сеть находится в `ipset-all.txt`, но отдельный домен фильтровать не следует;
- **`ipset-all.txt`** — IP-адреса и подсети;
- **`ipset-exclude-user.txt`** — IP-адреса и подсети для исключения.
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
